# 🛢️ Minyak Atsirian

![Minyak Atsirian](https://github.com/HariisDermawan/Company-Profile-Minyak-Atsirian/blob/main/img/bener.png)

## 📖 Deskripsi
**Minyak Atsirian** adalah website *company profile* yang menampilkan informasi produk **minyak tradisional/atsiri** sebagai warisan alami dengan berbagai manfaat untuk kesehatan dan perawatan tubuh.  
Website ini dirancang dengan tampilan modern, bersih, dan informatif untuk mendukung promosi produk secara digital.

---

## 🎯 Tujuan Proyek

| Tujuan | Keterangan |
|------|-----------|
| Informasi Produk | Menyediakan informasi lengkap produk Minyak Atsirian |
| Branding | Meningkatkan kepercayaan melalui tampilan profesional |
| Promosi | Media promosi digital produk minyak tradisional |
