# 🛢️ Minyak Atsirian

## Deskripsi
**Minyak Atsirian** merupakan website *company profile* yang menampilkan informasi produk **minyak tradisional/atsiri** sebagai warisan alami dengan berbagai manfaat untuk kesehatan dan perawatan tubuh.  
Website ini dirancang dengan tampilan modern, bersih, dan informatif untuk mendukung promosi produk secara digital.

---

## Tujuan
- Menyediakan informasi lengkap mengenai produk Minyak Atsirian  
- Meningkatkan kepercayaan pelanggan melalui tampilan website yang profesional  
- Menjadi media promosi digital bagi produk minyak tradisional  

---

## Fitur
- Profil perusahaan  
- Informasi produk dan manfaat  
- Tampilan responsif (mobile & desktop)  
- Halaman kontak dan informasi pemesanan  

---

## Teknologi
- HTML5  
- CSS3 / Tailwind CSS  
- JavaScript  
- PHP / Laravel *(opsional)*
